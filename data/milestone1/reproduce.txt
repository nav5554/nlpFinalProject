To reproduce from a fresh local checkout, run the following. Copy pilot.py and run.sh from this packet into the new checkout's data/milestone1/ before the last command. The first online run prepares the Hugging Face caches. The model uses CUDA on a CUDA host, MPS on Apple Silicon, and CPU otherwise. Keep the same backend and dependency versions for the closest match to the saved run.

    git clone https://github.com/nav5554/nlpFinalProject.git
    cd nlpFinalProject
    git checkout --detach 1475d644793f0492624d8c916cbab0fe0a5c639c
    uv venv --python 3.12 .venv
    uv pip install --python .venv/bin/python -r requirements.txt
    .venv/bin/python -c "from huggingface_hub import hf_hub_download; hf_hub_download('kuleshov-group/mdlm-no_flashattn-fp32-owt', 'model.safetensors', local_dir='mdlm-local', revision='60054720485e8aa080d5d2f3eaebafe1b829afb9')"
    mkdir -p data/milestone1
    # Copy pilot.py and run.sh here from the packet.
    bash data/milestone1/run.sh
